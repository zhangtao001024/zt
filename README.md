# 抖音弹幕获取工具

一个使用Go语言开发的抖音直播间弹幕实时获取工具，支持Web界面展示和数据导出。

## 功能特性

- 🎭 **实时弹幕获取**: 连接抖音直播间，实时获取弹幕消息
- 🌐 **Web界面**: 美观的Web界面，实时显示弹幕内容
- 📊 **数据统计**: 显示弹幕总数、用户数等统计信息
- 📥 **数据导出**: 支持将弹幕数据导出为CSV格式
- 🔄 **实时更新**: 使用WebSocket技术实现实时数据推送
- 📱 **响应式设计**: 支持PC和移动端访问

## 技术栈

- **后端**: Go语言
- **WebSocket**: gorilla/websocket
- **前端**: HTML5 + CSS3 + JavaScript
- **协议**: WebSocket, HTTP

## 快速开始

### 环境要求

- Go 1.19 或更高版本
- 现代浏览器（支持WebSocket）

### 安装运行

1. 克隆项目
```bash
git clone <repository-url>
cd douyin-danmu-tool
```

2. 安装依赖
```bash
go mod tidy
```

3. 运行程序
```bash
go run main.go
```

4. 访问Web界面
```
http://localhost:12000
```

### 使用方法

1. 打开Web界面
2. 在"直播间ID或URL"输入框中输入：
   - 抖音直播间的完整URL（如：https://live.douyin.com/123456789）
   - 或者直接输入房间ID（如：123456789）
3. 点击"连接直播间"按钮
4. 等待连接成功，开始实时接收弹幕
5. 可以使用"导出数据"功能将弹幕保存为CSV文件

### 命令行参数

```bash
go run main.go -host 0.0.0.0 -port 12000
```

- `-host`: 服务器监听地址（默认：0.0.0.0）
- `-port`: 服务器端口（默认：12000）

```
    "room_id": "123456789"

```

### 断开连接
```
POST /api/disconnect
```

### WebSocket连接
```
ws://localhost:12000/ws
```

## 实现原理

1. **WebSocket连接**: 通过分析抖音直播间的网络请求，构建WebSocket连接URL
2. **消息解析**: 接收并解析抖音的二进制消息格式（简化版本）
3. **实时推送**: 使用WebSocket将解析后的弹幕数据推送到前端
4. **数据处理**: 提取用户名、弹幕内容、时间戳等信息
